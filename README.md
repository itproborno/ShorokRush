# 🏍️ ShorokRush

**A first-person superbike highway game inspired by the Sylhet–Dhaka road.**
Dodge buses, trucks, cars and CNGs, pass the Ali Amjad’s Clock tower, and see how far you can ride. Built for phones first, and it also works on desktop.

▶ **Play now:** [itproborno.github.io/shorokrush]([https://itproborno.github.io/shorokrush/](https://itproborno.github.io/ShorokRush/))

---

## ✨ Features

- 🏍️ **Cockpit view** with a sport-bike dash: tachometer, shift lights, digital speed and gear display, and working mirrors
- 📱 **Tilt steering**: hold your phone upright and rotate it like a handlebar (on-screen buttons also available)
- 🛑 **Braking** with a strong slowdown, brake glow and vibration on phones
- 🚌 **Busy traffic**: buses, trucks, cars and auto-rickshaws, plus oncoming traffic on the opposite carriageway
- ⚡ **Near-miss bonus**: pass a vehicle closely without touching it for extra points
- ❤️ **3 lives** per ride, with a separate best score for each difficulty
- 🎚️ **3 difficulty levels**: Easy, Medium and Hard. Every row of traffic leaves one lane open, so a careful rider can always get through
- 🕌 **Sylhet landmark**: Ali Amjad’s Clock tower appears along the road
- 🔊 **Synthesized engine sound** that follows revs, with gear-shift clicks and exhaust pops
- 🎵 **Energetic background music** with 3 tracks, plus volume controls and an on/off switch
- ⏸️ **Pause** at any time

## 🎮 Controls

| Action | Phone | Keyboard |
| --- | --- | --- |
| Steer | Tilt the phone left or right (or hold ◀ ▶) | ← → or A D |
| Brake | Hold **BRAKE** | S or ↓ |
| Pause | Pause button (top bar) | P, Esc or Space |

**Tip:** if tilt steers the wrong way, open **⚙ Sound, tilt and help** and tap **Invert**. Tap **Calibrate** to reset your neutral position.

## 🎚️ Difficulty

| Level | Speed | Traffic gaps | Difficulty rises |
| --- | --- | --- | --- |
| Easy | Slower | Wide | Slowly |
| Medium | Fast | Medium | Normally |
| Hard | Very fast | Tight | Quickly |

## 🛠️ Built with

- [Three.js](https://threejs.org/) for the 3D highway (loaded from a CDN)
- HTML5 Canvas for the cockpit and dashboard
- Web Audio API for the engine sound and music (all generated by code, no audio files)
- Plain JavaScript in a **single `index.html` file**

## 🚀 Run it yourself

1. Download or clone this repository.
2. Open `index.html` in a browser, or host it with GitHub Pages (**Settings → Pages → main / root**).

For best results, use a real HTTPS address. Phone tilt sensors and sound work most reliably there.
